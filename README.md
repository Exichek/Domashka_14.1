# E-commerce

Учебный проект интернет-магазина на Python. Развивается в рамках домашних заданий **14.1**, **14.2** и **15.1**. В проекте отрабатываются объектно-ориентированное программирование, инкапсуляция, свойства, методы класса и магические методы.

## Функциональность

### Класс `Product`

Товар содержит название (`name`), описание (`description`), количество на складе (`quantity`) и приватную цену (`__price`).

- Свойство `price` возвращает цену, а сеттер позволяет изменить её только на положительное значение. При попытке установить ноль или отрицательную цену прежняя цена сохраняется и выводится сообщение `Цена не должна быть нулевая или отрицательная`.
- Класс-метод `new_product()` создаёт экземпляр `Product` из словаря с данными.
- Магический метод `__str__()` возвращает строку в формате `Название продукта, X руб. Остаток: X шт.`.
- Магический метод `__add__()` складывает полную стоимость двух товаров на складе: `цена_1 × количество_1 + цена_2 × количество_2`.

### Класс `Category`

Категория содержит название (`name`), описание (`description`) и приватный список товаров (`__products`).

- Метод `add_product()` добавляет объект `Product` в категорию и увеличивает общий счётчик товаров.
- Свойство `products` возвращает строки с информацией обо всех товарах категории, по одному товару на строку.
- Магический метод `__str__()` возвращает строку `Название категории, количество продуктов: X шт.`, где `X` — **сумма значений `quantity` всех товаров в категории**.
- Атрибут класса `category_count` считает количество созданных категорий.
- Атрибут класса `product_count` считает количество объектов товаров, включённых в категории, **а не сумму складских остатков**.

## Установка и запуск

Для управления зависимостями используется [Poetry](https://python-poetry.org/).

Установить зависимости:

```bash
poetry install
```

Запустить демонстрационный сценарий задания 15.1:

```bash
poetry run python main.py
```

## Тестирование

Тесты проверяют создание товаров и категорий, счётчики, добавление товаров, приватные атрибуты, геттеры и сеттер цены, создание товара из словаря, строковые представления товаров и категорий, а также сложение стоимости запасов двух товаров.

Запустить тесты:

```bash
poetry run pytest
```

Проверить покрытие:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Обновить HTML-отчёт:

```bash
poetry run pytest --cov=src --cov-report=html
```

Отчёт расположен в `htmlcov/index.html` и добавлен в репозиторий.

**Результаты для задания 15.1:** 18 успешных тестов; покрытие функционального кода — **100% (43 из 43 инструкций)**.

## Проверка качества кода

```bash
poetry run flake8 src tests main.py
poetry run isort --check-only src tests main.py
poetry run black --check src tests main.py
poetry run mypy src main.py
```

Правила Flake8 согласованы с форматированием Black в файле `.flake8`.
