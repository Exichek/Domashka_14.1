# E-commerce

Учебный проект по работе с объектно-ориентированным программированием на Python.

## Реализовано

В проекте реализованы основные сущности интернет-магазина:

- класс `Product`;
- класс `Category`;
- хранение информации о товарах;
- хранение списка товаров внутри категории;
- автоматический подсчет количества категорий;
- автоматический подсчет количества товаров.

## Класс Product

Класс `Product` содержит следующие атрибуты:

- `name` — название товара;
- `description` — описание товара;
- `price` — цена товара;
- `quantity` — количество товара в наличии.

## Класс Category

Класс `Category` содержит следующие атрибуты:

- `name` — название категории;
- `description` — описание категории;
- `products` — список объектов класса `Product`.

Также класс содержит атрибуты класса:

- `category_count` — количество созданных категорий;
- `product_count` — количество товаров во всех созданных категориях.

## Установка

Для установки зависимостей используется Poetry.

```bash
poetry install
```

## Запуск проекта

```bash
python main.py
```

## Тестирование

Для запуска всех тестов:

```bash
poetry run pytest
```

Для проверки покрытия функционального кода:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Для создания HTML-отчета о покрытии:

```bash
poetry run pytest --cov=src --cov-report=html
```

HTML-отчет сохраняется в директории `htmlcov`.

Текущее покрытие функционального кода тестами — 100%.

## Проверка качества кода

Проверка Flake8:

```bash
poetry run flake8 src tests main.py
```

Проверка сортировки импортов:

```bash
poetry run isort --check-only src tests main.py
```

Проверка форматирования Black:

```bash
poetry run black --check src tests main.py
```

Проверка типизации mypy:

```bash
poetry run mypy src main.py
```
