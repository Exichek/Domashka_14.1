
# E-commerce

Учебный проект интернет-магазина на Python.

Проект развивается в рамках домашних заданий **14.1, 14.2, 15.1, 16.1 и 16.2**.

В проекте изучаются объектно-ориентированное программирование, инкапсуляция, магические методы, наследование, абстрактные классы, множественное наследование и миксины.

## Функциональность

### Абстрактный класс BaseProduct

Базовый абстрактный класс для всех продуктов.

Реализован с использованием `ABC` и `abstractmethod`.

Определяет обязательные методы:
- `__str__()` — строковое представление продукта.
- `__add__()` — сложение стоимости продуктов.

Экземпляр `BaseProduct` нельзя создать напрямую.

### Класс CreationLogMixin

Миксин для автоматического вывода информации при создании продукта.

Реализованы:
- `__init__()` — выводит информацию о созданном объекте.
- `__repr__()` — формирует строковое представление объекта с названием класса и параметрами конструктора.

Для получения параметров конструктора используется `inspect.signature()`.

Пример вывода:

```text
Product('Телефон', 'Описание', 1000.0, 5)
```

Миксин включён в цепочку наследования `Product` и работает также при создании `Smartphone` и `LawnGrass`.

### Класс Product

Основной класс для представления товара.

Наследуется от `CreationLogMixin` и `BaseProduct`.

Атрибуты:
- `name` — название товара.
- `description` — описание товара.
- `__price` — приватная цена.
- `quantity` — количество товара на складе.

Реализованы:
- Геттер и сеттер `price` с проверкой положительного значения.
- Класс-метод `new_product()` для создания товара из словаря.
- Магический метод `__str__()` для строкового представления.
- Магический метод `__add__()` для вычисления стоимости двух товаров.

Сложение разрешено только между объектами одинаковых классов. Для проверки используется `type()`.

При сложении разных типов вызывается `TypeError`.

### Класс Smartphone

Наследник класса `Product`.

Дополнительные атрибуты:
- `efficiency` — производительность.
- `model` — модель.
- `memory` — встроенная память.
- `color` — цвет.

Общие атрибуты и методы наследуются от `Product`.

Для вызова родительского конструктора используется `super().__init__()`.

### Класс LawnGrass

Наследник класса `Product`.

Дополнительные атрибуты:
- `country` — страна-производитель.
- `germination_period` — срок прорастания.
- `color` — цвет.

Общие атрибуты и методы наследуются от `Product`.

Для вызова родительского конструктора используется `super().__init__()`.

### Абстрактный класс BaseCatalogEntity

Общий абстрактный родитель для классов `Category` и `Order`.

Содержит общие атрибуты:
- `name` — название.
- `description` — описание.

Определяет обязательный абстрактный метод `__str__()`.

Реализован в рамках дополнительного задания 16.2.

### Класс Category

Класс для представления категории товаров.

Наследуется от `BaseCatalogEntity`.

Атрибуты:
- `name` — название категории.
- `description` — описание категории.
- `__products` — приватный список товаров.
- `category_count` — количество созданных категорий.
- `product_count` — количество объектов товаров в категориях.

Реализованы:
- `add_product()` — добавляет товар в категорию.
- `products` — возвращает строковый список товаров.
- `__str__()` — отображает название категории и общее количество единиц товара на складе.

Метод `add_product()` использует `isinstance()`.

Добавлять можно только объекты `Product` и его наследников. При передаче неподходящего объекта вызывается `TypeError`.

### Класс Order (дополнительное задание)

Класс для представления заказа на один товар.

Наследуется от `BaseCatalogEntity`.

Атрибуты:
- `product` — ссылка на приобретаемый товар.
- `quantity` — количество приобретаемых единиц.
- `total_price` — итоговая стоимость заказа.
- `name` — название товара.
- `description` — описание товара.

При создании заказа автоматически рассчитывается стоимость:

`total_price = product.price * quantity`

Реализованы:
- Проверка типа товара через `isinstance()`.
- Проверка положительного количества.
- Магический метод `__str__()` для отображения заказа.

При передаче неподходящего товара вызывается `TypeError`.

При нулевом или отрицательном количестве вызывается `ValueError`.

Создание заказа не изменяет количество товара на складе.
