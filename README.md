
# E-commerce

Учебный проект интернет-магазина на Python.

Проект развивается в рамках домашних заданий **14.1, 14.2, 15.1 и 16.1**. В нём изучаются объектно-ориентированное программирование, инкапсуляция, магические методы, наследование классов и проверка типов.

## Функциональность

### Класс Product

Базовый класс для представления товара.

Атрибуты:
- `name` — название товара.
- `description` — описание товара.
- `__price` — приватный атрибут цены.
- `quantity` — количество товара на складе.

Реализованы:
- Геттер и сеттер `price` с проверкой положительного значения.
- Класс-метод `new_product()` для создания товара из словаря.
- Магический метод `__str__()` для строкового представления товара.
- Магический метод `__add__()` для вычисления суммарной стоимости товаров на складе.

В задании 16.1 метод `__add__()` доработан: складывать можно только товары одного класса. Для проверки используется `type()`. При попытке сложения объектов разных классов вызывается `TypeError`.

### Класс Smartphone

Наследник класса `Product`, представляющий смартфон.

Дополнительные атрибуты:
- `efficiency` — производительность.
- `model` — модель смартфона.
- `memory` — объём встроенной памяти.
- `color` — цвет.

Общие свойства и методы наследуются от `Product`. Для инициализации базовых атрибутов используется `super().__init__()`.

### Класс LawnGrass

Наследник класса `Product`, представляющий газонную траву.

Дополнительные атрибуты:
- `country` — страна-производитель.
- `germination_period` — срок прорастания.
- `color` — цвет.

Общие свойства и методы наследуются от `Product`. Для инициализации базовых атрибутов используется `super().__init__()`.

### Класс Category

Класс для представления категории товаров.

Атрибуты:
- `name` — название категории.
- `description` — описание категории.
- `__products` — приватный список товаров.
- `category_count` — количество созданных категорий.
- `product_count` — количество объектов товаров в категориях.

Реализованы:
- Метод `add_product()` для добавления товара в категорию.
- Геттер `products` для получения строкового списка товаров.
- Магический метод `__str__()` для отображения названия категории и общего количества единиц товара на складе.

В задании 16.1 метод `add_product()` дополнен проверкой `isinstance()`.

В категорию разрешено добавлять экземпляры `Product` и его наследников, включая `Smartphone` и `LawnGrass`.

При попытке добавить объект неподходящего типа вызывается `TypeError`.

## Установка и запуск

Для управления зависимостями используется Poetry.

Установка зависимостей:

```bash
poetry install
```

Запуск демонстрационного сценария домашнего задания 16.1:

```bash
poetry run python main.py
```
