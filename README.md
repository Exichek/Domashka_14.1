# E-commerce

Учебный проект интернет-магазина на Python. Проект развивается в рамках домашних заданий **14.1** и **14.2** и посвящён объектно-ориентированному программированию, инкапсуляции, свойствам и методам классов.

## Реализованная функциональность

### Класс `Product`

Класс описывает товар и содержит следующие атрибуты:

- `name` — название товара;
- `description` — описание товара;
- `quantity` — количество товара на складе;
- `__price` — приватный атрибут цены.

Для работы с ценой реализовано свойство `price`:

- `@property` возвращает текущую цену;
- `@price.setter` изменяет цену, только если новое значение больше нуля;
- при нулевой или отрицательной цене прежнее значение сохраняется, а в консоль выводится сообщение `Цена не должна быть нулевая или отрицательная`.

Класс-метод `new_product()` принимает словарь с данными товара и возвращает новый объект `Product`.

### Класс `Category`

Класс описывает категорию товаров и содержит следующие атрибуты:

- `name` — название категории;
- `description` — описание категории;
- `__products` — приватный список объектов `Product`.

Реализованы методы и свойства:

- `add_product(product)` — добавляет товар в приватный список с помощью `append()` и увеличивает общий счётчик товаров на единицу;
- `products` (`@property`) — возвращает строку со всеми товарами категории в формате `Название продукта, X руб. Остаток: X шт.\n`.

Атрибуты класса:

- `category_count` — количество созданных категорий;
- `product_count` — суммарное количество объектов товаров, добавленных в категории (не сумма складских остатков `quantity`).

При создании категории оба счётчика обновляются автоматически.

## Установка и запуск

Для управления зависимостями используется [Poetry](https://python-poetry.org/).

Установка зависимостей:

```bash
poetry install
```

Запуск демонстрационного сценария из задания 14.2:

```bash
poetry run python main.py
```

## Тестирование

В проекте проверяются:

- инициализация товаров и категорий;
- автоматический подсчёт категорий и товаров;
- добавление товара в категорию;
- строковое представление товаров и пустой категории;
- приватность списка товаров и цены;
- создание товара из словаря методом `new_product()`;
- чтение цены, успешное изменение цены и отклонение нулевой или отрицательной цены.

Запуск тестов:

```bash
poetry run pytest
```

Проверка покрытия тестами:

```bash
poetry run pytest --cov=src --cov-report=term-missing
```

Генерация HTML-отчёта:

```bash
poetry run pytest --cov=src --cov-report=html
```

Отчёт можно открыть локально через `htmlcov/index.html`. Он также добавлен в репозиторий.

**Результат для задания 14.2:** 13 успешных тестов, покрытие функционального кода `src` — **100%**.
